# Dog Shop Sinop — WordPress

Tema WordPress próprio para **Dog Shop Sinop**, pensado para uma loja de produtos e cuidados para cães e gatos em Sinop, MT.

## Estrutura

Este repositório contém um tema WordPress instalável em `wp-content/themes/dogshop-sinop`. Ele oferece uma página inicial responsiva, apresentação da loja, categorias, vitrine de produtos, contato pelo WhatsApp e compatibilidade com WooCommerce.

## Instalação

1. Baixe este repositório como ZIP ou clone-o para `wp-content/themes/dogshop-sinop`.
2. No painel WordPress, acesse **Aparência → Temas** e ative **Dog Shop Sinop**.
3. Para catálogo e carrinho, instale e configure o plugin WooCommerce.
4. Edite telefone/WhatsApp, endereço e horário em **Aparência → Personalizar → Dados da loja**.
5. Defina a página inicial em **Configurações → Leitura** ou deixe o tema usar automaticamente o template de página inicial.

## Personalização

- Paleta: verde folha, creme e coral.
- Nome, chamada, endereço, telefone, WhatsApp e horário configuráveis no Personalizador.
- Sem WooCommerce, a página inicial exibe uma chamada para a loja e orienta o visitante a entrar em contato.
- Com WooCommerce ativo, as categorias e produtos publicados aparecem automaticamente.

## Requisitos

- WordPress 6.0+
- PHP 7.4+
- WooCommerce (opcional, recomendado para vendas online)

## Domínio

Preparado para o site **dogshopsinop.com.br**. A configuração do domínio e a instalação do WordPress na hospedagem são etapas separadas.
